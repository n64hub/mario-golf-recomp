# Mario Golf's frame-dump plan: one run through every screen a player meets, for N64Recomp-browser's
# tools/frame_dump.mjs (tools/remote_frame_dump.sh) and tools/capture_window.ps1, whose headers say each step. It is
# played in a 16:9, a 4:3 and a 32:9 window and tools/frame_check.mjs reads the three dumps: frame_check fails only
# what a plan plays, so a scene a player reports a fault in that this doesn't reach is added here by the work that
# fixes it.
# Its times are seconds since the program started; each until waits on the game's RAM (the USA ROM's addresses,
# syms/) and moves the later steps on by its wait, so the three runs keep step with the game, not the clock.
# Overlays: the loaded byte at the head of each 0x28-byte entry of the overlay table at 0x800B5F58 (CLAUDE.md, The
# code; tools/shader_survey.js): 8 the title, 3 the main menu and the menus after it, 4 a hole's flyover, 2 any hole
# (with 11 in most modes, 13 in Ring Shot and Training), 16 the end credits. Keys are the keyboard's defaults: Enter
# Start, Space A, WASD the stick. A press can be lost on a busy host, so each step whose miss would leave the plan out
# of step presses until RAM shows it took: the pause (1 in the low byte of 0x800C306C while paused) and its menu's
# cursor (the low byte of 0x80224924, the item from 0), whose last item, W from the first, is Save and Quit (by the
# save menu), Return to Menu or Quit Game; the main menu is waited for with A pressed, which a save menu takes and the
# main menu's zoom drops.
