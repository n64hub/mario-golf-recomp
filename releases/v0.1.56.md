The black round the Koopa shell iris on Koopa Park is solid. Like v0.1.0 it contains no game data: you need your own ROM of the USA release (a big-endian `.z64`: the 32 MiB cartridge, SHA-1 `e2c4e7a905b29529b49a1619a401fe699224829b`, or the common 24 MiB dump of it, which the launcher pads back).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `MarioGolfRecompiled-v0.1.56-windows-x64.zip` and run `MarioGolfRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `MarioGolfRecompiled-v0.1.56-linux-x64.tar.gz` and run `MarioGolfRecompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2).

**What's new:**

- **The iris between screens:** at a hole's start and end on Koopa Park, a faint line of the picture behind showed through the black beside the Koopa shell, at its widest, out to the screen's sides. The shell's picture ends there one step short of black, and the game repeats that edge across the rest of the screen (a console does too, inside its 4:3 picture); with Enhancements On (the default) the black round the shell is solid. In a 4:3 window the course no longer shows in thin strips at the screen's sides through the wipe ([#165](https://github.com/n64hub/mario-golf-recomp/issues/165)).

The same game plays in a browser at [n64hub.com/mario-golf](https://n64hub.com/mario-golf/). The [README](https://github.com/n64hub/mario-golf-recomp#readme) has what works and how to build it yourself; reports are welcome on the [issues page](https://github.com/n64hub/mario-golf-recomp/issues).
