A new option puts the four golfers of Mario Golf for the Game Boy Color at character select. Like v0.1.0 it contains no game data: you need your own ROM of the USA release (a big-endian `.z64`: the 32 MiB cartridge, SHA-1 `e2c4e7a905b29529b49a1619a401fe699224829b`, or the common 24 MiB dump of it, which the launcher pads back).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `MarioGolfRecompiled-v0.1.30-windows-x64.zip` and run `MarioGolfRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `MarioGolfRecompiled-v0.1.30-linux-x64.tar.gz` and run `MarioGolfRecompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2).

**What's new:**

- **The Game Boy golfers:** Game Boy Golfers, a new option on the General tab, puts Kid, Sherry, Azalea and Joe, the golfers of Mario Golf for the Game Boy Color, at character select (issue 82). On a console the four come only through a Transfer Pak holding the Game Boy game. A second option, Game Boy Golfers' Stats, picks their stats: Normal, the clubs the game has for them (drives of 205-210 yards, about as long as the other golfers), or Test, the developers' test values the game also holds (Kid drives 500 yards, Sherry 400, Azalea 300 and Joe 200). Game Boy Golfers is Original (off) unless you turn it on, and the browser page has both options too.

The same game plays in a browser at [n64hub.com/mario-golf](https://n64hub.com/mario-golf/). The [README](https://github.com/n64hub/mario-golf-recomp#readme) has what works and how to build it yourself; reports are welcome on the [issues page](https://github.com/n64hub/mario-golf-recomp/issues).
