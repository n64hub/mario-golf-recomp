The course behind the pause menu and the leaderboard reaches the window's edges, with no streaked bars at the sides. Like v0.1.0 it contains no game data: you need your own ROM of the USA release (a big-endian `.z64`: the 32 MiB cartridge, SHA-1 `e2c4e7a905b29529b49a1619a401fe699224829b`, or the common 24 MiB dump of it, which the launcher pads back).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `MarioGolfRecompiled-v0.1.58-windows-x64.zip` and run `MarioGolfRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `MarioGolfRecompiled-v0.1.58-linux-x64.tar.gz` and run `MarioGolfRecompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2).

**What's new:**

- **The edges behind the pause and the leaderboard:** while a menu stands over the course (the pause menu, the leaderboard and score card from it, and the leaderboard a Tournament hole ends on), the game draws the course from a copy of its last frame. That copy was read only inside the console's 8-pixel border, so on a wide screen its outermost columns were repeated out to the window's left and right edges as streaked bars, each 1/40 of the window's width, as the gameplay view had before v0.1.55. It is now read across its whole width, so the course runs on to both edges behind those menus as it does in play ([#174](https://github.com/n64hub/mario-golf-recomp/issues/174)).

The same game plays in a browser at [n64hub.com/mario-golf](https://n64hub.com/mario-golf/). The [README](https://github.com/n64hub/mario-golf-recomp#readme) has what works and how to build it yourself; reports are welcome on the [issues page](https://github.com/n64hub/mario-golf-recomp/issues).
