No more dashes round the letters of the distance label over the aim point. Like v0.1.0 it contains no game data: you need your own ROM of the USA release (a big-endian `.z64`: the 32 MiB cartridge, SHA-1 `e2c4e7a905b29529b49a1619a401fe699224829b`, or the common 24 MiB dump of it, which the launcher pads back).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `MarioGolfRecompiled-v0.1.77-windows-x64.zip` and run `MarioGolfRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `MarioGolfRecompiled-v0.1.77-linux-x64.tar.gz` and run `MarioGolfRecompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2).

**What's new:**

- **The aim label's letters:** at a resolution above the console's, the distance and height over the landing point as a shot is aimed ("12Y DW / 208Y") had dark and light dashes over, under and beside its letters. The game draws them with the console's filter on, which at the whole pixel a console puts them on samples each texel as it is; at a higher resolution it blended in the edges of the letters beside them in the font. The label is now drawn texel for texel, as on a console, as the red pin flag already was ([#219](https://github.com/n64hub/mario-golf-recomp/issues/219)).

The same game plays in a browser at [n64hub.com/mario-golf](https://n64hub.com/mario-golf/). The [README](https://github.com/n64hub/mario-golf-recomp#readme) has what works and how to build it yourself; reports are welcome on the [issues page](https://github.com/n64hub/mario-golf-recomp/issues).
