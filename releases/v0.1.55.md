The picture's outer edges stay sharp on a hole as the view moves. Like v0.1.0 it contains no game data: you need your own ROM of the USA release (a big-endian `.z64`: the 32 MiB cartridge, SHA-1 `e2c4e7a905b29529b49a1619a401fe699224829b`, or the common 24 MiB dump of it, which the launcher pads back).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `MarioGolfRecompiled-v0.1.55-windows-x64.zip` and run `MarioGolfRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `MarioGolfRecompiled-v0.1.55-linux-x64.tar.gz` and run `MarioGolfRecompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2).

**What's new:**

- **The picture's edges on a hole:** with the course drawn to the window's edges, they smeared as the view moved. While you aimed, swung and watched the ball fly, the game drew the frame before again, and its outermost columns, 8/320 of the window's width at each side, repeated one column across them, a bar of streaks that slid as the aim turned. And wherever the camera tilted up, as it does following a ball's flight, the sky ended a few lines short of the window's top, which kept older frames' pictures there. Both edges now show the course and the sky as the rest of the picture does ([#150](https://github.com/n64hub/mario-golf-recomp/issues/150)).
