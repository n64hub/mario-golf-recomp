The far ball moves smoothly in flight, and the wipe from the title to the main menu keeps the old screen whole. Like v0.1.0 it contains no game data: you need your own ROM of the USA release (a big-endian `.z64`: the 32 MiB cartridge, SHA-1 `e2c4e7a905b29529b49a1619a401fe699224829b`, or the common 24 MiB dump of it, which the launcher pads back).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `MarioGolfRecompiled-v0.1.41-windows-x64.zip` and run `MarioGolfRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `MarioGolfRecompiled-v0.1.41-linux-x64.tar.gz` and run `MarioGolfRecompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2).

**What's new:**

- **The far ball moves smoothly in flight:** at a display rate above the game's 30, a ball far from the camera, drawn as a dot of colour two pixels by one, now moves on every frame the display shows, to a quarter pixel, where it held its place for a whole game frame and then stepped a pixel ([#96](https://github.com/n64hub/mario-golf-recomp/issues/96)).
- **The wipe between the title and the main menu:** in a wide window, the old screen now stays whole until its tiles go, as on a console: the new screen no longer shows in a band round it from the wipe's first frame, and the main menu's sign and board no longer stay over the title to the wipe's end ([#119](https://github.com/n64hub/mario-golf-recomp/issues/119)).

The same game plays in a browser at [n64hub.com/mario-golf](https://n64hub.com/mario-golf/). The [README](https://github.com/n64hub/mario-golf-recomp#readme) has what works and how to build it yourself; reports are welcome on the [issues page](https://github.com/n64hub/mario-golf-recomp/issues).
