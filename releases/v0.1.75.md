No more caps over the sun's lens flare at a high frame rate. Like v0.1.0 it contains no game data: you need your own ROM of the USA release (a big-endian `.z64`: the 32 MiB cartridge, SHA-1 `e2c4e7a905b29529b49a1619a401fe699224829b`, or the common 24 MiB dump of it, which the launcher pads back).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `MarioGolfRecompiled-v0.1.75-windows-x64.zip` and run `MarioGolfRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `MarioGolfRecompiled-v0.1.75-linux-x64.tar.gz` and run `MarioGolfRecompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2).

**What's new:**

- **The sun's lens flare:** as the sun goes off the top of the picture, the flare's circles no longer show a detached cap above each one, and a second copy lower down, between the game's frames. It showed with the frame rate above the game's own, as the circle beyond the sun was cut at the screen's corner ([#156](https://github.com/n64hub/mario-golf-recomp/issues/156)).

The same game plays in a browser at [n64hub.com/mario-golf](https://n64hub.com/mario-golf/). The [README](https://github.com/n64hub/mario-golf-recomp#readme) has what works and how to build it yourself; reports are welcome on the [issues page](https://github.com/n64hub/mario-golf-recomp/issues).
