The hills behind a course stay whole as the camera pans. Like v0.1.0 it contains no game data: you need your own ROM of the USA release (a big-endian `.z64`: the 32 MiB cartridge, SHA-1 `e2c4e7a905b29529b49a1619a401fe699224829b`, or the common 24 MiB dump of it, which the launcher pads back).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `MarioGolfRecompiled-v0.1.29-windows-x64.zip` and run `MarioGolfRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `MarioGolfRecompiled-v0.1.29-linux-x64.tar.gz` and run `MarioGolfRecompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2).

**What's new:**

- **No seam at the top of the hills:** as the camera swung over a course at the start of a hole (Mini Golf's first hole, behind the tee), a thin line of sky could flicker across the top of the picture, with the hills above it offset sideways from the ones below (issue 81). The game draws its distant hills as a stack of thin strips and cuts the one that crosses the top of the screen. In the frames drawn between the game's own, the renderer drew that strip where the game's last frame put it, while the strips below it moved on smoothly. It now moves with them. The browser page has the same fix.
