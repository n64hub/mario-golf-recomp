Metal Mario's shine is smooth, as on a console. Like v0.1.0 it contains no game data: you need your own ROM of the USA release (a big-endian `.z64`: the 32 MiB cartridge, SHA-1 `e2c4e7a905b29529b49a1619a401fe699224829b`, or the common 24 MiB dump of it, which the launcher pads back).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `MarioGolfRecompiled-v0.1.64-windows-x64.zip` and run `MarioGolfRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `MarioGolfRecompiled-v0.1.64-linux-x64.tar.gz` and run `MarioGolfRecompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2).

**What's new:**

- **Metal Mario's shine:** at any resolution above the console's, the reflection on Metal Mario (silver and gold, on Play Modes and on the course) showed as hard-edged squares. The game builds it each frame as a tiny 32x32 picture from pieces of the screen, and the renderer drew that picture at the window's resolution, so its squares no longer blended into each other as they do on a console. It is now blended square to square as on a console: a smooth sheen ([#186](https://github.com/n64hub/mario-golf-recomp/issues/186)).
