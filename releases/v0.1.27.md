The end credits' bottom line no longer wobbles sideways, and the MAIN MENU sign no longer shows a line of sky across it. Like v0.1.0 it contains no game data: you need your own ROM of the USA release (a big-endian `.z64`: the 32 MiB cartridge, SHA-1 `e2c4e7a905b29529b49a1619a401fe699224829b`, or the common 24 MiB dump of it, which the launcher pads back).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `MarioGolfRecompiled-v0.1.27-windows-x64.zip` and run `MarioGolfRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `MarioGolfRecompiled-v0.1.27-linux-x64.tar.gz` and run `MarioGolfRecompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2).

**What's new:**

- **The end credits rise smoothly:** at a display rate above the game's own, the line of text coming up at the bottom of the end credits wobbled a pixel sideways from frame to frame, like a wave (issue 61). In the frames drawn between the game's own, the renderer paired each letter with its shadow a pixel beside it, since it had trimmed the two differently where they meet the bottom of the credits' area, so it drew the line a pixel aside there. It now pairs what the game drew, and the line rises a pixel a frame without moving sideways. The browser page has the same fix.
- **The MAIN MENU sign:** the bobbing MAIN MENU sign no longer shows a line of sky across it (issue 76). The browser page has the same fix.
