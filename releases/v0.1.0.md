The first release of Mario Golf: Recompiled for Windows and Linux: a native PC port of the N64 game made by static recompilation. It is not an emulator and contains no game data: you need your own ROM of the USA release (a big-endian `.z64`: the 32 MiB cartridge, SHA-1 `e2c4e7a905b29529b49a1619a401fe699224829b`, or the common 24 MiB dump of it, which the launcher pads back). Other regions and revisions are not supported.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `MarioGolfRecompiled-v0.1.0-windows-x64.zip` and run `MarioGolfRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `MarioGolfRecompiled-v0.1.0-linux-x64.tar.gz` and run `MarioGolfRecompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). Pick your ROM with **Load ROM**, then **Start Game**: the ROM is stored, so the next start goes straight to the game.

**What works:** the logos, the intro and the title; the main menu and the play modes; a Tournament on Toad Highlands, its holes' flyovers, swings and the ball's flight; the pause menu and its Save and Quit, which writes the tournament to the game's SRAM. Sound (the game's own audio code, recompiled), and keyboard and gamepad input, each gamepad playing a player of its own for up to four players. The Transfer Pak link with the Game Boy Color game is not there: the game finds no Transfer Pak, as on a console with none.

**Enhancements**, each an option on the settings menu's Graphics tab with an Original value that plays as the console does:

- High resolution at the window's size, with anti-aliasing
- Smooth motion at the display's refresh rate, blended between the game's frames
- Widescreen: in a window wider than 4:3 the course reaches the window's edges; the HUD and the menus stay in the middle 4:3 for now
- Keyboard and gamepad controls, rebindable

**Not checked yet:** the courses past Toad Highlands, the other play modes, a whole tournament, a saved tournament continued after a restart, several gamepads at once, long play sessions, and the Linux build on a GPU (it has been booted on Mesa's software Vulkan only). Reports are welcome on the [issues page](https://github.com/n64hub/mario-golf-recomp/issues).

The same game plays in a browser at [n64hub.com/mario-golf](https://n64hub.com/mario-golf/). The [README](https://github.com/n64hub/mario-golf-recomp#readme) has how to build it yourself.
