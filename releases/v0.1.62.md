In a wide window, the outer seams of Ring Shot's stage-select board match the one in the middle. Like v0.1.0 it contains no game data: you need your own ROM of the USA release (a big-endian `.z64`: the 32 MiB cartridge, SHA-1 `e2c4e7a905b29529b49a1619a401fe699224829b`, or the common 24 MiB dump of it, which the launcher pads back).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `MarioGolfRecompiled-v0.1.62-windows-x64.zip` and run `MarioGolfRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `MarioGolfRecompiled-v0.1.62-linux-x64.tar.gz` and run `MarioGolfRecompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2).

**What's new:**

- **Ring Shot's stage-select board in a wide window:** past the 4:3 picture the board's planks were the picture's outer columns mirrored, which drew the seams at the picture's sides as a wide pale band on the left and a wide dark one on the right, where the seam in the middle is a thin dark line and a light one. The planks now run on as if the picture repeated, so every seam has the middle one's dark and light edge, and in windows wider than 16:9 no doubled line comes near the screen's edges either ([#185](https://github.com/n64hub/mario-golf-recomp/issues/185)).

The same game plays in a browser at [n64hub.com/mario-golf](https://n64hub.com/mario-golf/). The [README](https://github.com/n64hub/mario-golf-recomp#readme) has what works and how to build it yourself; reports are welcome on the [issues page](https://github.com/n64hub/mario-golf-recomp/issues).
