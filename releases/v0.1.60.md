The red pin flag in the sky moves smoothly as you turn the view. Like v0.1.0 it contains no game data: you need your own ROM of the USA release (a big-endian `.z64`: the 32 MiB cartridge, SHA-1 `e2c4e7a905b29529b49a1619a401fe699224829b`, or the common 24 MiB dump of it, which the launcher pads back).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `MarioGolfRecompiled-v0.1.60-windows-x64.zip` and run `MarioGolfRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `MarioGolfRecompiled-v0.1.60-linux-x64.tar.gz` and run `MarioGolfRecompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2).

**What's new:**

- **The pin flag in the sky as the view turns:** at a display rate above 30, the red flag that floats over the pin while you aim moved in jerks as you turned the view with the D-pad, its pace changing 30 times a second while the course turned smoothly behind it. The game puts it on whole console pixels; it is now placed to a fraction of a pixel, so it moves much more smoothly with the course ([#166](https://github.com/n64hub/mario-golf-recomp/issues/166)).

The same game plays in a browser at [n64hub.com/mario-golf](https://n64hub.com/mario-golf/). The [README](https://github.com/n64hub/mario-golf-recomp#readme) has what works and how to build it yourself; reports are welcome on the [issues page](https://github.com/n64hub/mario-golf-recomp/issues).
